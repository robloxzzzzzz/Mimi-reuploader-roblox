# Происхождение проекта

Mimi Reuploader — переработка [ISpooferMotion](https://github.com/ISpooferMotion/ISpooferMotion) автора IncredibroXP. Базовый коммит `74bc647b146057436a8936fb0c92b3ebdcff26ad`. Изменены оформление, интерфейс, обработка ошибок, ввод ID, интеграция со Studio и сборка. Код распространяется по GPL-3.0-or-later.

Логотип предоставлен пользователем. Иллюстрация проводника взята из [переданного Pinterest-пина](https://ru.pinterest.com/pin/896638607054552659/).
